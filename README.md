# 📡 RF Signal Strength Analysis and Coverage Visualization

An interactive data science and machine learning project for analyzing RF signal strength, exploring network performance, visualizing geographical coverage, and predicting signal strength using a Random Forest regression model.

🌐 **Live Demo:** [RF Insight – Streamlit App](https://rfproject-64ecudn2tnrt2jaurcqheg.streamlit.app/)

---

## 📌 Project Overview

Wireless network performance varies across geographical locations due to differences in signal propagation, network conditions, and other environmental factors. Understanding these variations helps in analyzing coverage quality and identifying areas with weaker signal strength.

This project combines data analysis, geographical visualization, and machine learning to explore RF signal measurements and estimate signal strength from location and network performance features.

The project also provides an interactive web application called **RF Insight**, built using Streamlit.

## 🎯 Objectives

- Analyze RF signal strength and network performance measurements.
- Explore relationships between signal strength, throughput, latency, and network type.
- Visualize geographical signal measurements and coverage patterns.
- Develop a machine learning model to predict RF signal strength.
- Evaluate prediction performance using standard regression metrics.
- Present analytical findings through an interactive dashboard.

## ✨ Key Features

- **Overview Dashboard:** Summary statistics and high-level dataset insights.
- **Data Explorer:** Explore the dataset and its underlying measurements.
- **Signal Analysis:** Investigate signal strength distributions and relationships with network metrics.
- **Coverage Map:** Visualize geographical signal measurements and saved coverage visualizations.
- **Model Evaluation:** Assess regression performance using MAE, RMSE, and R².
- **ML Predictions:** Explore signal strength predictions generated by the trained model.
- **Interactive Interface:** Navigate analytical results through a Streamlit web application.


## 📊 Dataset

The dataset contains **16,829 records and 12 columns** of RF signal and network-related measurements.

The analysis includes geographical coordinates, signal strength, throughput, latency, and network type.

| Property | Description |
|---|---|
| Records | 16,829 |
| Columns | 12 |
| Target variable | Signal Strength (dBm) |
| Mean signal strength | Approximately −90.07 dBm |
| Median signal strength | Approximately −89.67 dBm |

The dataset is explored and prepared for visualization, statistical analysis, and machine learning.

## 🤖 Machine Learning Approach

A **Random Forest Regressor** is used to estimate signal strength from selected input features.

**Input features**
- Latitude
- Longitude
- Throughput
- Latency
- Network Type

**Target variable:** Signal Strength (dBm)

The trained model is evaluated on test data using standard regression metrics. A compressed model file is included to reduce storage requirements and support deployment.

### Model Performance

| Metric | Result |
|---|---:|
| Mean Absolute Error (MAE) | 3.2516 dB |
| Root Mean Squared Error (RMSE) | 4.1365 dB |
| R² Score | 0.3945 |

These results represent the current model's performance on the evaluated test set. The R² score indicates that there is room for further improvement in predictive performance.
